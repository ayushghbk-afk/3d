# Golden-path hardening audit — 2026-09-08

## Scope and baseline (before implementation)

This is a prioritized first pass, not completion of the nineteen-phase roadmap or a claim of exhaustive runtime verification. Inventory covers source, public/PWA assets, migrations, tests, build scripts and deployment documentation. Runtime tracing focused on boot/auth/router, project persistence/sync, history, animation and GLB boundaries. UI/GitHub/performance need further dedicated review.

Baseline: `npm install`, `npm run typecheck`, `npm test` (59 passing), `npm run build` all succeed; install reports zero vulnerabilities.

## Confirmed findings

1. **P0 integrity:** scene_objects, materials and animations have independent scene/project FKs. A user with edit permission on project B can submit a row naming a scene in A. RLS alone does not enforce relationship consistency.
2. **P0 persistence:** the generic IndexedDB helper resolves on request success, before transaction completion; a later abort can be reported as saved. Clear-queue transactions also lack an abort handler.
3. **P0 save status:** markDirty does not invalidate Saved immediately. Offline cloudSave returns without queuing; queue snapshots are created only after cloud errors. No exponential retry loop. Whole-document cloud saves span non-atomic requests and can overwrite concurrent work. These latter queue/atomic-cloud issues need a separate coordinated change, not an untested rewrite.
4. **P0 invites:** current named RPC contract is p_project_id uuid, p_code text. Migration 00003 rejects NULL codes and protects existing roles. No removal tombstone/ban model exists; removed users can rejoin using an unchanged invite. Ordinary members can read invite_code from project rows. Do not claim complete invite hardening.
5. **P1 creation:** project, owner membership and scene creation are separate requests. Interrupted provisioning needs retry/idempotency testing.
6. **P1 history/collaboration:** remote apply avoids checkpoints, but snapshot undo can still overwrite remote work. Avoid equating “no remote checkpoint” with conflict-safe undo.
7. **P1 export:** GLB exporter passes animations: []; full animation round-trip is not implemented.
8. **P1 cleanup/routing:** router has no generation guard around asynchronous mounts; imported geometry/material ownership needs a disposal review. disposeObject contains a no-op material traversal.
9. **Documentation:** ARCHITECTURE's empty-repository statement describes historical origin, not current state. WebGPU is detection/reserved loading, not an active renderer.

## Implementation plan

Small, testable first slice: composite scene/project constraints with safe existing-data handling; transaction-acknowledged IndexedDB writes and abort regression tests; invalidate Saved on edits; add local database and production-browser verification. Preserve formats and existing architecture.

## External verification boundary

No database-admin connection is configured for this session. A public frontend key cannot query pg_proc as an administrator. Do not change RPC argument order based on guesses; deployed function inspection, schema reload, real invite/two-user collaboration, email delivery and GitHub authenticated round trips remain external acceptance checks. No production migration is applied by this work.
